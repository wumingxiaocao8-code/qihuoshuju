# 委托复盘

为什么做（11-05 晚定的，`测试/2026-11-05_优化四项/小结.md` 第一节）：赚不赚钱几乎全看开盘那一下拿到多少正滑；挂近挂远要看真实进单率。模型量不准，只能拿每天的委托单攒。他选的是每天把文件发给我、我手动跑，所以每次都照下面同一套做，数字只从脚本出。

## 1. 收文件、放好

1. 认清每个文件是**谁的**、**哪种**：
   - 谁：老陆 / 同事 / 账号A / 账号B。他没说就问，别猜。
   - 哪种：有「报单价格」「挂单状态」列的是委托单；有「成交价格」「成交时间」的是成交记录。
2. 交易日：快期文件名里的 `261105` 就是 2026-11-05（夜盘算下一个交易日）。看不出来就问他。
3. **复制**（不是移动）到 `成交/委托记录/`，改名为：
   - `日期_谁_所有委托单.csv`、`日期_谁_成交记录.csv`（例：`2026-11-05_老陆_所有委托单.csv`）
   - 同名文件已经在了：先比较内容，一样就跳过，不一样就问他用哪个，不要直接覆盖。
4. 账号 A、B 的成交记录，他要做盈亏复盘时另按 `开盘tick/说明.md`「成交复盘」放 `成交/原始记录/`；委托复盘找不到 `委托记录/` 里的成交记录时，会自动用 `原始记录/日期_账号A.csv`。

## 2. 跑脚本

在 `开盘tick` 里用原版 Python（venv 的 python.exe 被智能应用控制拦了）：

```
C:\Users\Administrator\AppData\Roaming\uv\python\cpython-3.13.16-windows-x86_64-none\python.exe 委托复盘.py 2026-11-05
```

- 几天一起发：每天各跑一次；全部重算：`委托复盘.py --all`。
- 要那天的开盘 tick（`开盘tick/数据/日期_2100`、`_0900`）和 `竞价判断.csv`；缺了脚本会少算那次开盘，原样告诉他。
- 结果：`成交/委托记录/复盘/日期.md`（这天 + 累计）、`开盘委托.csv`（一单一行，累计）、`开盘组合.csv`（一组一行，累计）。全在 `成交/` 里，只留本机，**不要提交**。

## 3. 回复他

先读 `复盘/日期.md`，照这个顺序，用大白话：

1. **数据提示**：md 里「数据提示」原样说，并告诉他导出时要补勾什么（同事的委托单要「报单手数、成交手数、成交均价」，成交记录要「报单编号」）。
2. **这天**：每人几张开盘单、开盘那一秒成了几张；▲ / 重 的格子挂在几成、开仓价差比挂价差好几档（正滑档）、腿2 有没有少成。
3. **累计**：到达点 a、正滑 w 的中位数和单数，挂在几成 vs 进单率，「近」「远」够得着的比例。单数少就说「只是线索」。
4. **分析**（可以自由发挥，但数字只抄 md / csv）：比如这次的 a 比两年回放假设的 0.55–0.85 快还是慢；挂得近和远的单进单差多少；▲ 和 ✅ 的正滑差别；哪个品种腿2 老追丢。觉得值得深挖的，用 `开盘委托.csv`、`开盘组合.csv` 自己再算，脚本放 `测试/日期_委托分析/`。

## 4. 口径（写在脚本开头，改之前先读）

- 开盘单 = 开盘 0–2 秒报的开仓单，只算看板组合的腿1；首单按竞价后那张快照定价，重挂按那一秒 .5 那张（`测试/2026-11-05_逐单复现/程序规则表.md`）。
- 几成 =（挂价差 − 昨收价差）÷（猜首笔 − 昨收价差），浮层「近」= 0.2、「远」= 首笔半（0.5，ag sn ni 1/3）。
- 到达点 a、正滑 w、近 / 远够得着、正滑档的定义见 `开盘tick/委托复盘.py` 文件开头。
- 同事那种委托单没手数、成交记录没报单编号的，每单的 a、w、进单率算不了，只有按组合的开仓价差。
- 攒到两三周（约 400 张开盘单）再拿 a 和进单率去重跑挂几成（`测试/2026-11-05_挂几成重跑/`）；在那之前不改挂法。
