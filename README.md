# 期货数据

一键获取 **上期所 / 上期能源** 的仓储数据（仓单日报 + 库存周报），附带近 20 个交易日 / 12 周的走势和风险提示，以及指定品种的近期新闻和影响各品种跨月价差的因素。品种可以写中文名，也可以写代码（如 au、ag、cu）。

## 三种用法

**1. 更新数据：双击 `一键更新数据.bat`**
一次更新两样东西（先影响因素、后仓储），完成后浏览器打开汇总网页，网页上方有两个标签页：「仓储」和「影响因素」。全程不经过 AI，也不花钱。
直接双击打开 `output/仓储速览.html` 只是看上次的结果，不会更新。

「仓储」标签页：最上面是风险提示（【高】【中】【提示】三级），然后是每个品种的走势小图，鼠标放在线上的点可以看日期和数值。完整的分仓库明细和历史数据在 `output/仓储/日期/` 里的 CSV 文件，用 Excel 打开就行。
第一次运行要下载约 30 份历史报表，大约一两分钟；以后只下载新的，几秒就好。

「影响因素」标签页：所有品种的「近月 − 下月价差」和近 20 个交易日走势，以及按因素（美联储利率、伊朗局势、铜矿罢工……）分好组的近 7 天新闻，每个因素附一句「通常怎么影响价差」。
想要 AI 帮你筛新闻、写解读、记录伊朗局势这类长期事件，就对 AI 说「更新影响因素」，紫色的「AI 解读」部分会更新，并写明更新时间。
要关注哪些因素、用什么词搜，都在 `因素清单.json` 里，可以自己改，也可以让 AI 改。

**查某个品种的历史：双击 `查询品种历史.bat`**
输入品种代码（如 al、cu，或中文名「铝」）和往前看多少天（直接回车 = 365 天），浏览器会打开这个品种的走势图：仓单、库存小计、后备货、可用库容，以及起点、终点、区间最高最低。逐日 / 逐周明细在 `output/历史查询/` 里的 .md 和 CSV。数据最早能查到 2015 年；第一次查很长的时间段要下载一会儿，下载过的会存下来。

**2. 仓储数据 + 新闻速览：让任意 AI 助手来做**
在这个文件夹里打开任意 AI 助手（Claude Code、Codex、Cursor 等，用便宜的模型也行），对它说：

> 期货速览 铜 原油

它会读 `AGENTS.md` 里的说明，自己运行脚本、读结果，再把新闻整理成速览，存到 `output/速览/`。
在 Claude Code 里也可以直接输入 `/futures-brief 铜 原油`。

**3. 自己敲命令**

```
python futures_brief.py stock              仓单日报 + 库存周报
python futures_brief.py stock cu au        另外列出铜、黄金的分仓库明细和逐日数据
python futures_brief.py stock --history-days 60   回看 60 个交易日
python futures_brief.py spread             跨月价差参考（第一次下载约 3 年数据，之后自动更新）
python futures_brief.py history al --days 365                  铝过去 365 天的日报 + 周报
python futures_brief.py history 铝 铜 --start 20250101 --end 20251231   指定起止日期
python futures_brief.py news 铜 原油        近 3 天新闻列表
python futures_brief.py all 铜 原油         两样都要
python futures_brief.py factors            影响因素：按因素清单搜新闻 + 各品种近月−下月价差
python futures_brief.py factors 原油 铜     只看这几个品种
python futures_brief.py page               只重新拼网页（AI 写完解读后用）
```

## 数据从哪来

- 仓储：上期所官网「日周数据」页面（上期能源的原油、低硫燃料油、20号胶、国际铜也在同一张表里）。脚本每次都会自检：明细逐列相加必须等于交易所给的总计，对不上会显示 ⚠。
- 新闻：东方财富资讯搜索，按时间倒序。
- 跨月价差参考：只做 au、al、ao、rb、hc、pb、zn、sn、cu、nr、br。先算「仓单 ÷ 近月持仓」（覆盖率）在过去 3 年里排第几，再找历史上覆盖率排名差不多、离交割时间也差不多的日子，统计那时「近月 − 下月」价差的常见范围（中间 80%），看现在的价差是偏高、偏低还是在区间内。表里「覆盖率排名」只说覆盖率排第几，「价差在同类中的位置」才说现在的价差在同类日子里算高还是低（100% = 比所有同类日子都高）；「只看覆盖率的区间」不管离交割还有几天、只按覆盖率找日子，作为对照。下载的历史数据压缩保存，约 20–30 MB。
- 后备货：库存周报和趋势里多算了一列「后备货 = 库存小计 − 仓单」，也就是已经在交易所仓库、合格、但还没做成仓单的货，以及它比上周多了还是少了。
- 近月覆盖率提示：同样只看上面 11 个品种。把「仓单 ÷ 近月持仓」跟过去每月同一时段比，比 95% 的同期日子都低算【高】，比 85% 都低算【中】，并入风险提示里。覆盖率低 = 能交的货相对等着交割的合约少，近月容易被挤。
- 影响因素：新闻按 `因素清单.json` 里的搜索词去东方财富搜，再要求标题里有「必含」词（只看标题，噪音少很多，但小品种的新闻会比较少）。价差用上期所 / 上期能源的每日行情结算价，近月 / 下月 = 当前月份之后第一个 / 第二个挂牌的合约，覆盖全部 25 个品种（包括原油、燃料油、沥青、集运欧线）。「通常怎么影响价差」是常见说法，未经验证。AI 解读引用的新闻链接会被自动核对，不在抓到的新闻里会标红 ⚠。
- 风险提示：按固定规则自动判断，例如「近 5 个交易日仓单下降超过 30%」算【高】。规则写在 `仓储趋势` 文件末尾，数字可以在 `futures_brief.py` 里的 `RISK_RULES` 修改。它只说明数据变化，不构成买卖建议。

## 文件说明

| 文件 | 作用 |
|---|---|
| `futures_brief.py` | 取数据的程序，只用 Python 自带功能，不用安装别的东西 |
| `一键更新数据.bat` | 双击更新仓储数据和影响因素（新闻 + 价差），然后打开网页 |
| `查询品种历史.bat` | 双击后输入代码和天数，查某个品种过去的日报和周报 |
| `因素清单.json` | 要关注的因素、搜索词、通常怎么影响价差；可以自己改 |
| `AGENTS.md` | 给 AI 助手看的操作说明 |
| `CLAUDE.md`、`.claude/` | 让 Claude Code 也能读到上面的说明，并提供 `/futures-brief` 命令 |
| `output/` | 所有结果；`output/缓存/` 存下载过的历史报表；`output/因素/AI解读.json`、`长期事件.json` 是 AI 写的 |

如果交易所网站改版导致取不到数据，脚本会直接报错，不会给出错误的数字。
